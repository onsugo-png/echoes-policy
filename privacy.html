개인정보처리방침

여긴 어땠지?(이하 "앱")는 사용자의 개인정보를 소중히 여기며,

「개인정보 보호법」 및 관련 법령을 준수합니다.

---

## 1. 수집하는 개인정보 항목

| 항목 | 수집 방법 | 필수 여부 |

| --- | --- | --- |

| Google 계정 이메일, 이름, 프로필 사진 URL | Google Sign-In | 필수 |

| 기기 위치 정보 (위도/경도) | 앱 사용 중 GPS | 필수 |

| 음성 녹음 파일 (3~15초) | 사용자 직접 녹음 | 필수 |

| 사진 (선택 첨부) | 카메라 / 갤러리 | 선택 |

| 에코 메타데이터 (감정 컬러, 캡션, 잠금 시각) | 앱 내 입력 | 선택 |

앱은 광고 식별자(GAID), 연락처, 결제 정보를 수집하지 않습니다.

---

## 2. 수집 및 이용 목적

- 위치 정보: 에코를 현재 위치에 묻고 해당 위치에서 재생하기 위한 핵심 기능

- 음성·사진: 에코 콘텐츠 저장 및 재생

- 계정 정보: 로그인 인증, 기기 간 데이터 동기화

---

## 3. 보유 및 이용 기간

- 계정 삭제 시 모든 데이터 즉시 파기 (음성 파일 · 사진 · 계정 정보 포함)

- 앱 미사용 1년 경과 후 계정 비활성화 안내 후 파기

수집한 개인정보를 제3자에게 제공하지 않습니다.

단, 법령에 의한 수사기관 요청 시 예외입니다.

## 계정 및 데이터 삭제

### 앱 내에서 계정 삭제 방법

1. 앱 실행 → 우상단 마이페이지 진입

2. 화면 하단 "계정 삭제" 버튼 탭

3. 확인 다이얼로그 → "삭제"

이 동작으로 다음 데이터가 영구 삭제됩니다:

- 묻은 모든 음성 (오디오 파일 포함)

- 첨부한 모든 사진

- 시간 캡슐 알림

- 캡션 / 컬러 / 위치 기록

- Google 계정 연결 정보

### 보관 기간

계정 삭제 즉시 모든 데이터가 서버에서 영구 삭제됩니다.

백업 시스템에서도 30일 이내 자동 정리됩니다.

### 데이터 일부 삭제

- 개별 느낌 삭제: 지도에서 마커 탭 → 재생 화면 하단 "삭제" 버튼

- 또는 마이페이지 → 나의 느낌 → 카드 좌측 슬라이드 → 삭제

### 앱 외부에서 삭제 요청

이메일: [echoes.diary.contact@gmail.com](mailto:echoes.diary.contact@gmail.com)

제목: "계정 삭제 요청 — [등록 Google 이메일]"

영업일 기준 7일 이내 처리 + 이메일 회신.
